### Editing a graphic
The graphics are built from [`graphics/graphics.html`](graphics/graphics.html). Open it in Chrome to see them all, and edit the text in any code editor. To export a PNG again, open Chrome DevTools (F12), right-click the `<section>` for that graphic and choose **Capture node screenshot**. Or, for a quick change, edit the PNG in Canva.

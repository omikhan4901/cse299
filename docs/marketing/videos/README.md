# Animated mockups

Short screen recordings of the real app with sample data (Nusrat Jahan, a CSE graduate).
Each comes in four shapes:

| File ending | Size | Use it for |
|---|---|---|
| `-square.mp4` | 1080×1080 | Facebook and Instagram feed posts, Facebook groups |
| `-portrait.mp4` | 1080×1350 | Instagram feed (takes more of the screen than square) |
| `-story.mp4` | 1080×1920, phone layout | Reels, Stories, TikTok, WhatsApp status |
| `-wide.gif` | 960×540 | GitHub README, LinkedIn articles, anywhere a GIF plays inline |

They're silent with captions on screen, so they work with the sound off (how most people
scroll). To re-record after the app changes, see [`../video/record.mjs`](../video/record.mjs).
